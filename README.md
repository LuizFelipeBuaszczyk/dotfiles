# DOTFILES

Neste repositório é armazenado os meus dotfiles. Fique a vontade para utiliza-los! 

## Como usar?

Se você deseja utilizar alguma configuração minha, siga o seguinte guia e também acesse o diretório desejado e veja se existem possíveis dependências externas.


1. Clone o repositório

```bash
git clone https://github.com/luizfelipebuaszczyk/dotfiles
```

2. Entre no diretório e pegue o caminho

```bash
cd dotfiles/ && pwd
```

3. Acesse o diretório de configurações e crie um link simbólico

```bash
ln -s [pwd]/nvim nvim
```
> Escolha a configuração que você deseja aplicar, neste caso eu utilizei o nvim.
